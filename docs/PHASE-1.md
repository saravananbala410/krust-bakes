# Phase 1 — Krust ordering foundation

1. Establish the brand system, responsive storefront, category navigation and variant-level quick ordering.
2. Implement a persistent Zustand cart with minimum delivery validation and real-time inclusive-GST totals.
3. Deliver validated checkout, payment-method selection, order confirmation, WhatsApp handoff and printable GST invoice.
4. Deliver role-oriented admin views for orders, products, customers, abandoned carts, store/tax settings and append-only audit history.
5. Wire production persistence with the Prisma schema, Auth.js role sessions, transactional order creation and payment webhooks.
6. Harden with API authorization, idempotency, rate limiting, audit writes, automated tests and deployment monitoring.
